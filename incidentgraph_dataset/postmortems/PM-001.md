# Postmortem PM-001: Settlement batch failed

Incident: INC-001
Date: 2026-10-01

## Timeline (UTC)
- 08:57 Deployment DEP-100 (v2.8.1) completed.
- 09:03 DB_CONNECTION_POOL_EXHAUSTED appeared in settlement-worker logs.
- 09:07 Job JOB-284 failed.
- 09:15 Alert fired.
- 09:22 Investigation identified the contributing failure.

## Root cause
Database connection pool exhausted due to a connection leak introduced in settlement-worker v2.8.1.

## Corrective action
Inspect active sessions and pool metrics; patch connection handling; restart worker only after approval.

## Prevention
Introduce regression tests and service-level alerts for db connection pool saturation.
