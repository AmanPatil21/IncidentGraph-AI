# Postmortem PM-003: Invoice export stuck

Incident: INC-003
Date: 2026-10-03

## Timeline (UTC)
- 08:57 Deployment DEP-102 (v2.10.1) completed.
- 09:03 S3_ACCESS_DENIED appeared in invoice-exporter logs.
- 09:07 Job JOB-355 failed.
- 09:15 Alert fired.
- 09:22 Investigation identified the contributing failure.

## Root cause
Service account IAM policy update removed object write permission for invoice export bucket.

## Corrective action
Compare policy revisions; request least-privilege permission restoration; replay failed exports after approval.

## Prevention
Introduce regression tests and service-level alerts for iam policy regression.
