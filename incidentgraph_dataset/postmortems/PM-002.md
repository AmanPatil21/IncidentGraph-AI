# Postmortem PM-002: Payment authorization timeout spike

Incident: INC-002
Date: 2026-10-02

## Timeline (UTC)
- 08:57 Deployment DEP-101 (v2.9.1) completed.
- 09:03 UPSTREAM_GATEWAY_TIMEOUT appeared in payment-api logs.
- 09:07 Job JOB-310 failed.
- 09:15 Alert fired.
- 09:22 Investigation identified the contributing failure.

## Root cause
External gateway latency exceeded the configured 2-second timeout during a provider degradation.

## Corrective action
Verify gateway status; enable approved failover route; monitor retry volume.

## Prevention
Introduce regression tests and service-level alerts for gateway latency degradation.
