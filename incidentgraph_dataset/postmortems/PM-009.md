# Postmortem PM-009: Webhook delivery failures

Incident: INC-009
Date: 2026-10-09

## Timeline (UTC)
- 08:57 Deployment DEP-108 (v2.16.1) completed.
- 09:03 TLS_CERT_EXPIRED appeared in webhook-dispatcher logs.
- 09:07 Job JOB-589 failed.
- 09:15 Alert fired.
- 09:22 Investigation identified the contributing failure.

## Root cause
Outbound webhook signing proxy certificate expired at 00:00 UTC.

## Corrective action
Rotate certificate; validate trust chain; replay queued deliveries with approval.

## Prevention
Introduce regression tests and service-level alerts for expired tls certificate.
