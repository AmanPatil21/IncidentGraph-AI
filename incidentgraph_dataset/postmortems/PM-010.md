# Postmortem PM-010: Account ledger write errors

Incident: INC-010
Date: 2026-10-10

## Timeline (UTC)
- 08:57 Deployment DEP-109 (v2.17.1) completed.
- 09:03 DB_DEADLOCK appeared in ledger-api logs.
- 09:07 Job JOB-620 failed.
- 09:15 Alert fired.
- 09:22 Investigation identified the contributing failure.

## Root cause
Concurrent ledger updates acquired account locks in inconsistent order.

## Corrective action
Review transaction ordering; add bounded retry; test locking change.

## Prevention
Introduce regression tests and service-level alerts for database deadlocks.
