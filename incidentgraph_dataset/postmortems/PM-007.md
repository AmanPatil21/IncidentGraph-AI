# Postmortem PM-007: Merchant payout delay

Incident: INC-007
Date: 2026-10-07

## Timeline (UTC)
- 08:57 Deployment DEP-106 (v2.14.1) completed.
- 09:03 RATE_LIMIT_429 appeared in payout-service logs.
- 09:07 Job JOB-501 failed.
- 09:15 Alert fired.
- 09:22 Investigation identified the contributing failure.

## Root cause
Partner bank API rate limit was exceeded by a new unbounded polling loop.

## Corrective action
Throttle polling; implement exponential backoff; coordinate with partner.

## Prevention
Introduce regression tests and service-level alerts for partner api rate limiting.
